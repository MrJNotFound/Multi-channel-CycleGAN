# 显微图像工具 v0.6.0

面向 Windows 与 macOS 的 Python 科研工具，按实际数据流分为四个模块：**大图拼接 → 刀纹去除 → 大图合成 → 大图分割**。每个模块都可独立选择输入，同时支持把上一环节的结果直接带到下一环节。

界面基于 PySide6。拼接模块只估算和微调参数，不生成大图；局部预览只读取 2×2、3×3 或 4×4 缩略图。大图合成模块通过磁盘缓存、分块融合和金字塔 OME-BigTIFF 写出，不会把数千张原图同时放进内存。

推荐流程：先用原始图像找到拼接参数并保存方案，再按需批量去除刀纹，然后在“大图合成”中选择原始或去刀纹后的图像文件夹和同一份拼接方案，最后进入“大图分割”。

## 安装和启动

需要 Python 3.12 或更新版本。本工具使用自己目录下的 `.venv`，与仓库根目录的训练环境分开。

Windows PowerShell 首次安装（从仓库根目录执行）：

```powershell
cd tool\large-image-tool
python --version  # 确认至少为 3.12；若较旧，请改用已安装的 3.12+ 解释器
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
```

macOS / Linux 首次安装：

```bash
cd tool/large-image-tool
python3 -m venv .venv  # python3 需为 3.12 或更新版本
.venv/bin/python -m pip install -e .
```

如果已经安装 uv，也可以在本工具目录创建并安装环境：

```bash
uv venv --python 3.12
uv pip install -e .
```

日常启动（在本工具目录执行，无需激活环境）：

```bash
python run.py
```

`run.py` 会优先使用同目录 `.venv` 的解释器，并自动加入本地 `src` 路径。也可以从仓库根目录执行：

```bash
python tool/large-image-tool/run.py
```

显式指定解释器启动，在本工具目录的 Windows PowerShell 中使用：

```powershell
.\.venv\Scripts\python.exe run.py
```

macOS / Linux 中使用：

```bash
.venv/bin/python run.py
```

VS Code 的 Python 解释器可选择 `tool/large-image-tool/.venv/Scripts/python.exe`（macOS / Linux 为 `tool/large-image-tool/.venv/bin/python`），方便运行测试或直接运行包内模块。后文的 `python -m large_image_tool.cli ...` 命令也需使用这个环境的解释器。

如果提示 `Missing dependency`，请执行提示中的安装命令。不要用仓库根目录的 Python 3.10 环境安装本工具。

## 输入命名规则

- 文件名主体必须是纯数字，例如 `000001.png`、`000002.tif`、`000003.jpg`，最多支持到用户设置的网格容量。
- 建议从 `000001` 开始并统一补零；若存在 `000000`，程序会明确按零开始编号。
- 按数字值排序，因此 `2.png` 在 `10.png` 前。
- 支持 PNG、JPEG、TIFF 和 BMP；同一批图应具有相同像素尺寸。
- 缺失编号只警告并保留空位；超出行×列容量的文件不加载。
- 扫描方式、起点和路径由用户明确指定，程序不会猜测扫描顺序。

## 1. 大图拼接

先选择“蛇形”或“逐行/列返回”，再点选四角中的起始位置。界面随后用九宫格路径图给出横向优先和纵向优先两种可能；蓝点是起点，实线箭头是连续扫描，虚线是返回移动。

### 自动拼接

可设置：

- 重叠搜索范围：0%–30%；
- 图块旋转搜索范围：-15°–15°；
- X/Y 各自抽样的相邻图数量；
- 配准最长边。

“配准最长边”只控制自动估算时送入配准算法的缩略图尺寸。例如 1024 px 表示先把每张图按比例缩小，使最长边不超过 1024 像素。数值越大，能保留更多细节，但估算更慢、占用内存更多；它不改变原图或最终大图的分辨率。

自动流程用均匀分布的相邻图抽样估算 X/Y 重叠和 CCD 图块旋转，并用同一抽样上限做第二遍带先验检查，最后给出三个全局参数。结果会直接写回“拼接参数”，用户可继续用滑块或数字输入微调。两遍计算都受“每方向抽样”限制，不会因总图数增加而遍历所有接缝；同一图对的候选与可信度共用一次 FFT 结果。

几何模型只有三个全局参数：`X 重叠`、`Y 重叠`、`图块旋转`。

相位相关在高通梯度通道上产生多个候选，再综合真实重叠区相关性、重叠/旋转先验、异常边和 2×2 环路一致性选取结果。周期刀纹仍可能造成错误峰，因此界面会报告低可信接缝，并始终保留手动参数。

### 手动拼接

直接调整全局 X/Y 重叠和图块旋转，可排除 `17, 31-35` 形式的坏图编号。无需拖动单张图块。局部预览可选 2×2、3×3、4×4，并可指定中心编号。

“重叠取值”可连续调节重叠区的图像来源，局部预览和大图合成使用相同逻辑。图块按采集顺序定义前后；旋转后画布外的空角作为透明区域处理，不会用黑色斜边盖住另一张图的有效像素。

该模块的输出是可重新编辑的 `.stitch.json` 拼接方案，其中包含网格、扫描路径、重叠、旋转、重叠取值、坏图编号和图块尺寸。确认局部预览后保存方案；完整大图统一在“大图合成”模块生成。

## 2. 刀纹去除

该模块分为“单张 / 大图”和“批量文件夹”两种明确的处理模式。两种模式都先选择样图并通过原图/处理后实时对比和“差异增强 ×4”确定算法参数，再在独立的输出区执行处理。

当前算法：

1. `FFT + Gaussian Notch`：在频域检测周期峰并用软高斯陷波抑制；适合稳定、接近平行的周期刀纹。
2. `方向校正 + 局部条纹模板相减`：沿刀纹分段估计稳健模板，只把条纹修正量映射回原图。支持间距不规则、周期非整数的刀纹；周期控制背景分离尺度，模板平滑控制细纹保留。旧参数文件中的 `periodic_template` 名称继续兼容。
3. `方向性 Median 残差滤除`：提取法向 Median 的残差，再筛选沿刀纹连续的分量，从原图扣除。默认核宽 51 原图像素；宽度应大于刀纹宽度的两倍，可按样图缩小。核过大仍可能削弱与刀纹同方向的细长结构。

三种算法都可调整去除强度，并可自动或手动指定刀纹法向角和周期。自动方向先分析频谱中的条纹方向，再用沿线投影细化，减少组织边界造成的误判；方向证据不足时跳过滤除。置信度是算法的相对证据分数，不是准确率。

整图证据不足时，会检查覆盖四角和边缘的重叠区域，并要求候选条纹具有足够的沿线连续性，避免仅凭组织纹理的频谱峰就执行滤除。局部检出时，预览原图用橙框标出处理范围，方向、周期和 FFT 频率也在该区域内估计；仅在框内滤除，并在内部边界平滑过渡。框外像素保持不变，保存的分析结果包含原图坐标 `processing_region`。这种补充检测适用于刀纹集中在角落、容易被整图统计和边缘窗函数削弱的情况。

法向与可见刀纹垂直：0° 对应竖直刀纹，±90° 对应水平刀纹；图像坐标中向右下为正角。切换预览图像后，自动识别出的法向角和周期会回填到控件；取消自动识别即可继续微调。周期、Median 核宽和模板平滑均按原图像素保存，缩略图预览会自动换算，旁路 `.preview.png` 也使用对应原图尺寸。

间距不规则时，“周期 / 主尺度”仅代表主导尺度，周期置信度可能较低。FFT 自动模式直接寻找多个频率峰，分块导出也保留该检测方式，不会强制换成单一周期的谐波。模板和 Median 方法只重采样修正量，避免把整张原图旋转两次造成模糊或位置偏移。

先用默认 FFT 检查样图；宽而不等间距的划痕可比较 Median 残差方法，缓慢弯曲或强度变化的条纹可比较局部模板。缩略图无法显示所有原始细节，确认参数时仍需检查输出原图与差异图；这三种方法都不能保证恢复刀纹覆盖处的真实组织结构。

FFT 的“频率峰/谐波上限”限制算法最多抑制多少组频域峰或周期谐波，并不是画面中肉眼可见的刀纹条数。默认 14 是较保守的起点；直接设为 50 更容易误伤样本细节，也会增加计算量。

“大图分块边长”只在处理单张超大图时出现。它表示算法每次处理的方形区域边长，用来限制内存峰值；它不会改变输出尺寸。较大的分块保留更多局部上下文但占用更多内存，较小的分块更省内存但处理开销和块边界风险更高。批量文件夹模式是逐张完整处理，因而隐藏这个选项。

文件夹模式保留原文件名，输出文件夹可直接交给“大图合成”。拼接参数仍来自去刀纹前保存的方案，避免刀纹滤波改变配准证据。

批量模式把当前选择的算法、强度和其他参数应用到整个文件夹。启用方向或周期自动识别时，每张图分别估算相应参数；关闭自动识别后，整批固定使用预览中显示的数值。每张结果先写入临时文件，完整写入后再替换目标文件，避免中断时留下半张图。

刀纹去除会改变像素。用于定量纹理测量或训练数据时，应先检查实时预览和差异图，并保留原图与参数文件。

## 3. 大图合成

分别选择图像文件夹和 `.stitch.json` 拼接方案。图像文件夹既可以是原始扫描图，也可以是批量去刀纹后的结果；程序会核对方案中记录的图块尺寸，防止错误组合。

“生成大图拼接缩略图”会按当前方案直接读取并缩小各图块，再合成为一张 PNG，不会先创建原始尺寸画布或 OME-TIFF。默认最长边为 2400 px，可在 800–4096 px 间调整；适合在正式合成前快速检查整幅图的排列、旋转、接缝和缺图位置。缩略图使用与正式合成相同的图块顺序、旋转和重叠取值，但它仅供观察，不能替代原分辨率大图用于测量或分割。

输出为无损金字塔 OME-BigTIFF，并生成系统图片查看器可直接打开的预览 PNG。右侧可浏览新生成的大图，也可独立打开已有的常见图像或 OME-TIFF；拖动平移，滚轮缩放。

## 4. 大图分割

- 输入普通图像或 OME-TIFF；
- 按固定切片尺寸，或按指定行数×列数分割；
- X/Y 重叠范围为 0%–30%，分割网格可整体旋转；
- 边缘可补黑、镜像填充或跳过不完整块；
- 输出 PNG、TIFF 或 JPEG；
- 自动生成 `manifest.csv` 和 `split_settings.json`，方便训练集追溯和复现；旧版 `.crop.json` 参数仍可打开。

## 文件和参数约定

| 环节 | 主输出 | 同步保存 |
|---|---|---|
| 大图拼接 | `<输入名>.stitch.json` | 网格、扫描路径、拼接参数和图块尺寸 |
| 刀纹去除（单图/大图） | `<输入名>_marks_removed.ome.tif` | `.preview.png`、`.toolmarks.json` |
| 刀纹去除（文件夹） | `<文件夹>_marks_removed/` | 原文件名、`toolmark_settings.json` |
| 大图合成缩略图 | `<图像文件夹>_stitched_thumbnail.png` | 不创建完整大图 |
| 大图合成 | `<图像文件夹>_stitched.ome.tif` | `.preview.png` |
| 大图分割 | `patch_r0000_c0000.<格式>` | `manifest.csv`、`split_settings.json` |

所有 JSON 均使用带版本号的可读文本格式。拼接方案同时记录源目录的绝对和相对引用，便于整批移动；v0.1 方案可自动迁移，旧“方向角”会转换为单一图块旋转，旧“正交偏差”会被忽略。

## 生成测试数据

生成一组带圆环刀纹、已知重叠与 CCD 旋转的模拟扫描图：

```bash
python -m large_image_tool.cli synthetic ./demo_tiles
```

自动配准诊断：

```bash
python -m large_image_tool.cli analyze ./demo_tiles --rows 5 --cols 6
```

刀纹去除也可从命令行运行：

```bash
python -m large_image_tool.cli remove-marks ./demo_tiles ./demo_tiles_marks_removed
```

测试：

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

## 输出规模与边界

数千张 3840×2160 彩色图的解码数据和最终无损大图可能达到数百 GB。合成前请保证输出盘可同时容纳磁盘工作缓存和 OME-TIFF。RAM 主要由一个输出分块、少量图块缓存和滤波工作区决定。

- 当前只处理单层彩色平面，不处理 Z-stack。
- 自动模型只求全局 X/Y 重叠和单一 CCD 旋转；图块中心严格保持正交规则网格，不做每图平移、旋转、缩放或非线性形变。
- 重复圆环纹理、暗角、曝光跳变和明显离焦仍可能降低自动配准可信度；应检查局部预览与低可信接缝数量。
- 三种刀纹算法的适用性取决于缺陷与刀纹的频率/方向是否重合。真实样本到位后，应以目标缺陷保真度为首要验收指标。
