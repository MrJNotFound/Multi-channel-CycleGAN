# 连续切片实例追踪算法改进方法报告

日期：2026-11-05  
实现：func_cell_tracking_v2.py  
范围：跨切片实例关联、轨迹生命周期和结果映射；合成数据生成逻辑保持原样。

## 1. 方法定位与改进目标

输入为已配准的连续二维实例标签图，目标是将属于同一个三维对象的不同层截面关联到同一轨迹。适用对象应在相邻切片中具有较连续的位置和形态。Z 表示空间切片序号，而非视频时间。

本次保留 Kalman 状态预测和线性分配框架，改进关联前的可行性判断、尺度相关噪声、形状代价、异常观测处理和输出可追溯性。Kalman 与线性分配相结合是 SORT 已有的技术路线；本实现是针对本项目连续切片的工程改进，不将这一组合本身作为新的算法贡献。[SORT 原始论文](https://arxiv.org/abs/1602.00763)

| 原实现的问题 | 本次修改 | 预期作用及边界 |
|---|---|---|
| 新轨迹立即进入未匹配处理，首层重复记录 | 先处理旧轨迹，再建立新轨迹 | 每条轨迹每个 Z 最多一个最终历史点 |
| 先求分配，再拒绝不合理配对 | 不可行配对在分配前设为不可选 | 保留其他可行匹配机会 |
| 分配没有明确的“不匹配”选项 | 每条轨迹增加独立虚拟列 | 无可行观测时可继续等待或结束 |
| 仅依赖质心距离和面积比例 | 加入位置不确定性与平移后的掩码 IoU | 在几何信息允许时提高关联区分度 |
| 面积与位置使用固定尺度的噪声 | 噪声随等效半径、面积变化 | 避免大小对象共用不合适的面积方差 |
| 仅按累计命中确认轨迹 | 连续命中确认，候选与已确认轨迹分开管理 | 抑制间歇噪声累积为确认轨迹；可能降低短目标召回 |
| 合并区域可能被分给其中一个对象 | 多轨迹掩码覆盖冲突检查 | 暂时保留各自身份，不强行分配合并观测 |
| 缺失预测立即写入历史并形成末端拖尾 | 只补全被前后观测夹住的间隙 | 最终轨迹不含无后续证据的末端延伸 |
| 显示阶段重新使用最近质心匹配 | 保存原始 label 与 track 的精确对应 | 绘图和标签体采用实际被接受的关联 |
| 图像读取失败静默跳过 | 默认明确报错，可显式按缺失层处理 | 缺失预算与真实层号保持一致 |

这些作用已通过小型确定性回归用例验证；尚未用真实标注切片量化准确率、召回率、ID 切换率或体积误差。

## 2. 输入、坐标与数据契约

### 2.1 输入要求

- 单层输入为二维、非负整数标签数组，或可读取的标签图像路径。
- 0 是背景，同层不同实例使用不同正整数。不同层可以重复使用或改变标签编号。
- 同层共享一个标签的离散像素被视为一个实例，不自动拆成连通域。若上游分割将多个对象使用同一个标签，需先纠正实例编码。[regionprops 官方定义](https://scikit-image.org/docs/stable/api/skimage.measure.html#skimage.measure.regionprops)
- 所有可用切片具有相同的图像尺寸，并在同一配准坐标系中。
- XY 和面积单位分别为像素、像素平方；Z 为等间距切片序号。当前不接受非等距物理 Z 坐标。
- 路径或数组可以通过迭代器逐层提供。输入不会被原地修改。
- None 显式表示缺失层；slice_indices 中跳过的整数层号也按缺失层处理。
- slice_indices 必须严格递增且与输入数量相同。起始层号可不为 0，起始层之前不生成缺失记录。
- 标签先在内部压缩为连续编号再提取区域，输出仍保留原始编号，避免稀疏大标签导致按最大 ID 分配大量区域槽位。

核心数组处理依赖 NumPy、SciPy、scikit-image。文件输入另外使用 scikit-image 的图像读取后端；核心已移除对 OpenCV 的强制依赖。

### 2.2 特征

每个区域提取：

    label, cx, cy, area, bbox

追踪内部还保留区域包围框内的布尔掩码。每条活动轨迹只保留最后一次观测的裁剪掩码，轨迹结束时释放；历史保存数值和标签对应关系，不保存所有切片的完整掩码。

默认过滤面积小于 15 像素的区域。该阈值应随图像分辨率和目标大小校准。

## 3. 状态估计与关联方法

### 3.1 Kalman 状态

保留六维线性状态：

\[
\mathbf{x}_z=[c_x,c_y,A,v_x,v_y,v_A]^\mathsf{T}
\]

观测为：

\[
\mathbf{y}_z=[c_x,c_y,A]^\mathsf{T}
\]

每前进一层：

\[
F=\begin{bmatrix}I_3&I_3\\0&I_3\end{bmatrix},\qquad
H=[I_3\quad0]
\]

\[
\hat{\mathbf{x}}_z=F\mathbf{x}_{z-1},\qquad
\hat P_z=FP_{z-1}F^\mathsf{T}+Q_z
\]

这里的速度表示单位切片的截面变化。缺失的整数层逐层预测，因此跳过层号也消耗缺失预算。

设等效半径 \(r=\sqrt{\max(A,1)/\pi}\)，观测标准差为：

\[
\sigma_{xy}=\max(\texttt{position\_noise},0.1r),\quad
\sigma_A=\max(1,\texttt{area\_noise\_ratio}\cdot\max(A,1))
\]

\[
R=\operatorname{diag}(\sigma_{xy}^2,\sigma_{xy}^2,\sigma_A^2)
\]

初始化 \(P_0=\operatorname{diag}(R_0,R_0)\)。预测时以各观测标准差的一半作为对应分量的随机加速度标准差；每个“值—变化率”二元组的过程噪声块为：

\[
Q_k=(0.5\sigma_k)^2
\begin{bmatrix}1/4&1/2\\1/2&1\end{bmatrix}
\]

更新使用线性方程求解增益，不显式计算协方差逆矩阵；协方差采用 Joseph 形式：

\[
P=(I-KH)\hat P(I-KH)^\mathsf{T}+KRK^\mathsf{T}
\]

更新后对称化，并将状态面积下限截为 1。此面积下限用于数值保护，不能视为真实对象仍然存在的证据。

### 3.2 关联前门控

对轨迹 i 与检测 j，定义半径归一化距离和面积比：

\[
d_{ij}=\frac{\|\mathbf{c}_j-\hat{\mathbf{c}}_i\|_2}{r_i},
\qquad q_{ij}=\frac{A_j}{\max(\hat A_i,1)}
\]

位置创新协方差使用预测 XY 协方差与按预测面积计算的 XY 观测噪声：

\[
S_{xy}=\hat P_{xy}+R_{xy}(\hat A_i)
\]

\[
m_{ij}=(\mathbf{c}_j-\hat{\mathbf{c}}_i)^\mathsf{T}
S_{xy}^{-1}(\mathbf{c}_j-\hat{\mathbf{c}}_i)
\]

Mahalanobis 门控利用预测不确定性判断观测是否合理，这一思路可见 Deep SORT。这里仅使用二维位置，没有采用其深度外观网络、八维状态或完整的按轨迹年龄级联方案。[Deep SORT 原始论文，第 2 节](https://arxiv.org/pdf/1703.07402)

配对须同时满足：

1. 位置距离不超过 pos_gate × min(2, 1 + 0.25 × missing_count)。
2. 二维位置平方 Mahalanobis 距离不超过 mahalanobis_gate。
3. 预测面积大于 split_min_area 时，面积比不得小于 split_area_ratio 或大于 merge_area_ratio。
4. 综合代价不得超过 cost_gate。

小面积截面不采用上述面积比例硬门控，以减少对象两端自然收缩或扩张时的误拒绝；它仍受位置、不确定性和总代价约束。

默认 Mahalanobis 阈值为 9.21，但本实现噪声参数未用真实数据标定，不将该阈值解释为已验证的统计覆盖率。

### 3.3 形状重叠与综合代价

将最后一次真实观测的掩码，按“预测质心减去该次观测质心”的位移平移，并与当前检测计算 IoU。平移取整后通过裁剪包围框求交，不使用周期回卷。暂不对掩码做旋转、缩放或非刚性变形。

对可行配对：

\[
C_{ij}=2d_{ij}+3|\log q_{ij}|
       +0.5\sqrt{\max(m_{ij},0)/\tau_m}
       +w_{\mathrm{IoU}}(1-\mathrm{IoU}_{ij})
\]

面积采用对数比，使相同比例的放大和缩小具有对称代价。IoU 作为软代价，而非必须相交的硬条件；形态改变时仍可能通过位置及面积关联。

不满足门控的配对设置为正无穷，在求解前禁止选择。每条轨迹另有独立虚拟列，代价为 cost_gate + 0.000001，表示该层不匹配。

实现分两阶段求解：

1. 已确认轨迹与所有未使用检测进行分配。
2. 候选轨迹与剩余检测进行分配。

每阶段是该子问题的最小代价分配，整个两阶段流程带有身份优先策略，不声称等价于一次无优先级的全局最优分配。实际调用 SciPy linear_sum_assignment；其当前官方实现采用修改的 Jonker–Volgenant 算法。[SciPy 官方说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.linear_sum_assignment.html)

### 3.4 合并与分裂异常

当一个检测同时覆盖至少两条已确认轨迹各自平移后掩码的 50%，且面积至少为这些轨迹最大预测面积的 1.3 倍，记录 merge_conflict。该检测暂不参与匹配，也不建立新候选轨迹；相关旧轨迹按缺失规则继续等待。

这项检查能保护“合并区域质心恰好靠近其中一个对象”时的另一条身份。它依赖几何重叠证据，不能证明发生了真实生物学合并。

分裂主要通过面积骤减门控处理：不可信碎片不能立即替代原有大对象的观测。未匹配碎片仍建立候选轨迹，短暂碎片通常因连续命中不足而不被确认。本次没有实现多碎片自动重组，也没有建立分裂/合并谱系图。

超过缺失容忍长度的合并或分裂，仍可能导致轨迹结束并产生新 ID。

## 4. 生命周期与缺失处理

### 4.1 轨迹确认

- 出生层只写入一次 matched，missing_count 为 0。
- match_count 记录累计观测次数。
- hit_streak 记录连续观测次数；遇到任何未匹配层即归零。
- hit_streak 达到 confirm_thresh 时，候选转为已确认。
- 已确认后不因短缺失降级回候选。
- 已确认轨迹允许 max_missing 个连续缺失层。
- 候选轨迹的限额为 min(candidate_max_missing, max_missing)。
- 超过限额，或未匹配时预测面积不大于 min_interp_area，则结束轨迹。

因此，“确认阈值 3”现在要求连续三次真实观测，包含出生层；这是相对于旧版累计确认的有意语义变更。

### 4.2 预测与最终补全分离

失配期间 Kalman 状态继续预测，但只保存待定缺失层号，产生 predicted 事件，不立即将其写进最终 history。

若之后重新匹配到同一轨迹，在最近左右两次观测 \(z_l,z_r\) 之间，以真实层号计算：

\[
w=\frac{z-z_l}{z_r-z_l},\qquad
[c_x,c_y,A]_z=(1-w)[c_x,c_y,A]_{z_l}+w[c_x,c_y,A]_{z_r}
\]

这些点写为 interpolated，并记录左右锚点及 method='linear'。这是一种数值轨迹插值，不是轮廓或体素插值，也不是后向 Kalman 平滑。

若轨迹结束或输入耗尽时仍未重新观测到对象，待定层全部丢弃。最终 history 从首次观测开始，到最后一次真实观测结束，不含外推尾部。

## 5. 输出接口与兼容性

原调用仍可使用：

    confirmed_tracks, fp_tracks, events = track_glomeruli(paths)

第二个返回值保留位置兼容，但实际含义是“未确认轨迹”。它不能直接作为经标注验证的假阳性数量。

每条轨迹：

- id：从 0 开始分配的轨迹编号；确认轨迹的 ID 可能不连续。
- history：按 Z 排序的 (z, cx, cy, area, status)，每个 Z 至多一条。
- matched 点保存真实区域质心和面积；Kalman 平滑状态保存在 X 中，不覆盖原始观测。
- interpolated 点保存前后观测之间的线性插值。
- matched_labels：{z: 原始实例标签}，只记录真实接受的观测，缺失层没有伪造标签。
- match_count、hit_streak：累计及连续命中数。
- active：完整序列处理返回时均已结束，不用它判断轨迹是否被确认。

映射辅助函数：

    detection_to_track = build_detection_to_track(confirmed_tracks)

返回 {z: {label: track对象}}。同层同标签若出现重复归属会明确报错。

vis_3d_tracking.py 和 napari_viewer.py 已改用该映射，移除了距离小于 80 像素的二次近邻猜测。run_tracking_v2.py 的拒绝统计也纳入了 merge_conflict 的受影响轨迹数。数据生成和现有 napari 掩码补全逻辑没有修改。

事件包括 new_candidate、matched、confirmed、predicted、interpolated、match_rejected、merge_conflict、terminated 和 missing_slice。插值事件在重新匹配时才产生，事件列表按产生顺序记录，因此其中的 z 不保证单调。match_rejected 只记录该未匹配轨迹附近最近的一个门控失败解释，不是所有被拒绝配对的穷举。

## 6. 参数与真实数据使用示例

| 参数 | 默认值 | 作用 |
|---|---:|---|
| max_missing | 3 | 已确认轨迹最大连续缺失层数 |
| candidate_max_missing | 1 | 候选轨迹最大连续缺失层数，且受 max_missing 限制 |
| confirm_thresh | 3 | 连续真实观测确认阈值 |
| pos_gate | 0.45 | 正常层的位移/预测等效半径门限 |
| mahalanobis_gate | 9.21 | 二维位置平方 Mahalanobis 门限 |
| split_area_ratio | 0.5 | 中部截面面积比下限 |
| merge_area_ratio | 2.0 | 中部截面面积比上限 |
| split_min_area | 400 | 启用面积比例硬门控的预测面积阈值 |
| min_interp_area | 25 | 未匹配时允许继续预测的面积下限 |
| min_area | 15 | 检测区域最小面积 |
| position_noise | 2.0 | 位置观测标准差下限，像素 |
| area_noise_ratio | 0.15 | 面积观测标准差相对比例 |
| iou_weight | 1.0 | 平移掩码 IoU 代价权重，可设 0 做消融 |
| cost_gate | 20.0 | 综合代价上限，代价定义已变，不应直接沿用旧版调参结论 |
| read_error | 'raise' | 文件读取失败时明确报错；可设为 'missing' 消耗一层缺失预算 |

文件命名为 slice_0001.tif 等时，在项目根目录运行以下逻辑：

~~~python
from pathlib import Path
from tool.code_3D_analysis.func_cell_tracking_v2 import (
    track_glomeruli,
    build_detection_to_track,
)

label_dir = Path("your_registered_instance_labels")
paths = sorted(
    label_dir.glob("slice_*.tif"),
    key=lambda p: int(p.stem.rsplit("_", 1)[1]),
)
indices = [int(p.stem.rsplit("_", 1)[1]) for p in paths]

confirmed, unconfirmed, events = track_glomeruli(
    paths,
    slice_indices=indices,
    max_missing=3,
    confirm_thresh=3,
    read_error="raise",
)
mapping = build_detection_to_track(confirmed)
for track in confirmed:
    print(track.id, track.matched_labels, track.history)
~~~

上游已提供 (Z,Y,X) 的标签数组时，可直接将其作为逐层可迭代输入。不要把原始染色图、普通灰度强度图或所有目标都为 1 的二值前景图直接当作多个实例标签输入。

### 7.1 修改前后的同输入对照

另外使用修改前的核心源码快照与当前实现，对相同输入做了五组对照。旧版的图像读取替换为等价的内存取图，不改变其预测、代价、匹配或生命周期逻辑；配对替代用例为两版提供相同的固定检测特征。

D 表示一个真实区域，E 表示无检测的空白标签层。

| 用例 | 修改前 | 修改后 |
|---|---|---|
| 单个出生层 [D] | 同一 z=0 记录两次 | z=0 只记录一次 |
| 末端缺失 [D,D,D,E,E] | 最终历史含 z=3、4 的外推尾部 | 最终历史止于最后观测 z=2 |
| 间歇命中 [D,E,D,E,D] | 累计三次命中，确认 1 条轨迹 | 连续命中不足，确认 0 条 |
| 有界缺失，左端 cx=29.5、右端 cx=32.5，中间两层缺失 | 两个缺失位置均为 29.5 | 按两端观测得到 30.5、31.5 |
| 低代价非法配对与稍高代价可行配对竞争 | 原轨迹在该层没有观测关联 | 原轨迹成功选择可行观测 |

间歇命中结果体现确认策略变更，有界缺失结果体现插值定义变更；二者均不是对真实组织精度的统计估计。最后一项验证的是门控执行顺序修复，测试文件中的 test_pre_assignment_gate_preserves_valid_alternative 固定了该行为。


## 8. 复杂度、限制与后续评价

设每层活动轨迹数 N、检测数 M、标签图像素数 P。特征提取包含标签压缩及区域统计；关联阶段建立 N×M 配对信息，每对掩码只比较相交裁剪区域。每阶段分配矩阵包含检测列及轨迹虚拟列，稠密分配的大规模开销仍需关注。输入可流式读取，但历史和事件随序列增长保留，并非整个算法常数内存。

当前限制：

1. 依赖配准质量。大幅错位和非刚性变形可同时破坏位置门控与掩码重叠。
2. 局部线性面积模型和线性间隙插值不能表达任意三维形态，补点仅为估计。
3. 连续确认有利于抑制间歇噪声，也会漏掉仅存在一两层的真实小对象。
4. 已确认优先可能偏向旧的错误身份；没有采用外观重识别或全序列图优化。
5. 合并保护只针对已有多条确认轨迹的重叠证据；首次出现即合并的目标缺少可分离身份。
6. 分裂、合并检测是几何启发式，不处理真实谱系；持续超过缺失预算会断链。
7. 核心没有修复实例掩码，没有新增体素插值、真实体积估计或标准跟踪评测器。
8. XY 未做各向异性物理尺度归一化；面积和像素阈值需按分辨率调整。

后续真实数据验证建议先固定配准与分割输入，保留独立调参与验证样本，对比旧版、仅修复生命周期版、加入门控版、加入 IoU 版和完整版本。统计跨层关联正确率/召回率、ID 切换、轨迹碎片、对象计数误差和缺失补点误差，分别汇报正常、漏检、合并、分裂及密集区域。阈值只在调参集选择，再在未用于调参的切片上报告结果。

如需体积分析，应将真实观测面积与插值面积的贡献分开报告，并结合实际切片间距；本次回归通过不能替代此项定量验证。
