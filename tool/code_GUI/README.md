# 3D_tomography GUI

基于 PyQt6 的四合一界面（左侧切换模块）：
- 图像处理：CLAHE、频域带阻滤波、缩放与旋转（带参数滑条和预览）。
- 图像配准：分层锚点-子序列配准（刚性/刚性+弹性），带参数输入、日志输出与后台线程。
- 图像拼接：横向/纵向、左右/上下方向、重叠宽度、黑色阈值，结果预览与保存。
- 区域分析：KMeans+分水岭分割、面积/圆度筛选；跨层 IoU 指标（±3 层加权）。

目录：`# 3D_pathology/code/GUI/3D_tomography.py`

依赖（主要）：
- PyQt6
- opencv-python
- numpy
- scikit-image
- SimpleITK
- pillow

运行方式：
- 在含上述依赖的 Python 环境中，执行 3D_tomography.py。
- 窗口左侧列表用于在四个模块间切换；右侧为参数与预览/日志。

使用提示：
- 区域分析中“跨层 IoU”要求输入为单通道整数标签图（0 背景）。
- 图像配准较耗时，界面使用后台线程执行，日志区域查看进度。弹性配准依赖 SimpleITK。
- 频域滤波角度为频谱条纹方向；带宽越大抑制带越宽。

已知事项：
- 若系统未安装 PyQt6 / SimpleITK，运行前请安装依赖（见 requirements.txt）。
- 某些大图像的预览会自动等比例缩放以适配窗口。
